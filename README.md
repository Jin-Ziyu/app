# Fan Quest 🎮

A cute, game-style tracker for my fandoms, school and portfolio.

- **Home**: a princess castle with Princess Mochi (studies with you during focus sessions), daily goals with ⚡ energy, XP and streaks
- **Collect**: Love and Deepspace (夏以昼 cards + official 周边 catalog), EXO, SEVENTEEN and and2ble photo collections, each K-pop page lit in its own lightstick colours
- **Rewards**: weekly quests, budget quest, bias love meter, badges
- **School**: my SIT timetable (from my .ics), a pixel focus timer that grows a garden, quizzes and deadlines, to-dos and SIT quick links
- **Me**: profile and portfolio links

Everything is plain HTML, CSS and JavaScript with no build step. Data is saved in the browser (`localStorage`) on each device. Use **Settings → Backup** to copy your data and restore it on another device.

## Put it on GitHub Pages

1. Create a new repository (for example `fan-quest`) and upload every file in this folder, including `.nojekyll`.
2. In the repo go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
3. After a minute it's live at `https://<your-username>.github.io/fan-quest/`.

To make it part of your portfolio site instead, put the files in a `fan-quest/` folder inside your `<username>.github.io` repo.

On a phone, open the link and choose **Add to Home Screen** to use it like an app.

Album and merch photos are cropped from fan-made and official reference charts for personal tracking.
